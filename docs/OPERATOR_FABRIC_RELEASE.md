# Operator Fabric Release

This release extends LIV8 Command Center from a dashboard into a local-first operating fabric.

## Included
- Creator Control Room: native Content Engine plus embedded Clipped It and OBS Remote compartments.
- Local Workspace MCP: allow-listed Mac filesystem tools for Juno/Claude-style clients, with no shell execution.
- Trading Guardian: MNQ Bible + QQE + Hybrid AI alert qualification, advisory only.
- Hybrid AI alert parser: exact ENTRY/TP/SL lifecycle messages from the TradingView script.
- Juno hierarchy: executive operator → specialist leads → bounded worker agents.
- Desktop voice router placement fix and environment configuration for creator apps.

## Not included / intentionally gated
- arbitrary remote shell execution
- unrestricted Mac filesystem access
- autonomous live trading
- bypasses around external-write approvals

## Deployment split
Public Render API: web/API integrations and safe cloud services.
Mac Mini private bridge: local workspace MCP, OBS Remote, local Ollama/Juno, private studio controls.
